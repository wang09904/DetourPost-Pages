Besoin d’aide avec Detour Post ?

Pour toute question concernant votre compte, vos lettres ou vos achats, écrivez-nous à detourpost@aivolo.studio. Décrivez brièvement le problème et, si vous les connaissez, indiquez le modèle de votre appareil ainsi que les versions d’iOS et de l’app. Pour votre sécurité, n’envoyez pas par e-mail de mot de passe, code de connexion, code d’invitation, clé de récupération, texte de lettre ou photo. En cas de problème de sécurité, utilisez la fonction de signalement dans l’app. Les conséquences d’un blocage ou d’un signalement sont précisées dans les Conditions d’utilisation. Pour une demande relative à vos données personnelles, consultez la Politique de confidentialité.
